BELAJAR KOREA PWA V2

Versi ini memiliki 179 kosakata, mode campuran, mode ulangi kata sulit, mode semua kata, dan penyimpanan progres per kata di browser.

CARA UPDATE DI GITHUB PAGES:
1. Ekstrak ZIP.
2. Buka repositori GitHub yang sama.
3. Add file > Upload files.
4. Unggah file-file dari folder hasil ekstraksi ini (index.html, app.js, style.css, manifest.json, sw.js, icon.svg).
5. Pilih Commit changes. Timpa file lama saat diminta.
6. Tunggu deployment GitHub Pages selesai, lalu buka kembali situs. Jika masih versi lama, tutup aplikasi dan muat ulang; cache mungkin perlu beberapa saat.

CATATAN:
- Ini masih prototipe belajar pribadi. Data kosakata ditulis sebagai kumpulan awal dan perlu ditinjau jika digunakan sebagai materi formal.
- Pengenalan suara memakai Web Speech API bahasa Korea (ko-KR) dan perlu dukungan browser/koneksi.
- Pencocokan suara memeriksa teks hasil transkripsi, bukan mengukur ketepatan aksen secara ilmiah.
- Progres disimpan di localStorage browser pada perangkat yang sama. Menghapus data situs dapat menghapus progres.
- Mode campuran berisi hingga 20 kata per sesi; total kumpulan kosakata di versi ini adalah 179 kata. Mode "Semua kata" memuat seluruh kumpulan dalam satu sesi.
